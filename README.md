# Video topic-tagging experiments

A small 2023 experiment extracting speech from video and using Underthesea's existing Vietnamese classifier to tag transcript topics. This repository does not train a new topic-classification model.

## Scripts

```sh
python3 transcribe_video.py -video data/input.mp4 -l vi -noise no
python3 compare_transcripts.py data/reference-transcripts data/processed-transcripts
```

The first script requires FFmpeg, speech recognition and the updated dependencies listed in `requirements.txt`. The optional `deep` noise mode also requires DeepFilterNet's native `deep-filter` executable. Run from the repository root. Dataset files are not included.

The comparison utility matches related transcript filenames and writes `result/result.txt`:

- Pairwise TF-IDF cosine similarity measures transcript overlap.
- Filename-label agreement compares topic tags encoded in filenames. It is **not an independent classifier-accuracy measurement**. Any use as an evaluation requires documenting how those tags were produced and supplying independent ground-truth labels.

`experiments/compare_transcripts_legacy.py` and `experiments/compare_transcripts_v1.py` are earlier comparison variants. `convert.py` converts numeric words in text; its unused import of a missing subtitle utility was removed during cleanup.

This is preserved as an exploratory research component. It has not been rerun against its original dataset or validated with current external APIs. See [third-party notices](THIRD_PARTY_NOTICES.md).


## Dependency maintenance (2026-10-28)

Python dependency files are in the repository root. The main lock targets **CPython 3.12 on Linux x86_64**. `requirements.in` contains direct dependencies; `requirements.txt` is generated by the command in its header. Run the command from that same directory. Resolve again before using another Python version or platform. No machine-wide pip freeze or obsolete Conda export is used.

The optional `deep` noise mode uses the [native Rust DeepFilterNet CLI](https://github.com/Rikorose/DeepFilterNet#deep-filter), independently of Python/Torch packages. Put a trusted `deep-filter` binary on PATH or set `DEEP_FILTER_BIN` to its absolute path; set `DEEP_FILTER_MODEL` for a specific trusted model. The adapter resamples input to 48 kHz with FFmpeg and preserves existing output filenames. Those legacy suffixes do not prove which model was used. The external binary and models were not downloaded, executed or audited in this maintenance pass.

Lockfile advisory checks, source parsing and lightweight regression tests were performed during maintenance. **No application dependency environment was installed, and no full frontend build, database integration, model inference or training was run.** These archived prototypes still need runtime/integration verification before deployment. Run older experiment modules from the repository root with `python3 -m experiments.<module_name>` so local package imports resolve.
